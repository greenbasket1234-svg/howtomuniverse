HOWTOM 유니버스 v1.1.0 실행 안내

[Railway 권장]
- railway.toml이 npm ci -> npm run build -> node server.mjs 순으로 실행합니다.
- Variables: HOWTOM_ADMIN_EMAIL, HOWTOM_ADMIN_PASSWORD, JWT_SECRET, HOWTOM_DATA_DIR=/data
- Volume을 /data에 연결하면 광고주/블로그 데이터가 재배포 후에도 유지됩니다.

[로컬 개발]
1. Node.js 20 이상 설치
2. 프로젝트 폴더에서 npm run dev
3. 패키지가 없으면 자동 설치를 시도합니다.
4. 화면과 API 서버가 함께 실행됩니다.

[로컬 운영 형태 확인]
1. npm ci
2. npm run build
3. HOWTOM_ADMIN_EMAIL / HOWTOM_ADMIN_PASSWORD / JWT_SECRET 환경변수 설정
4. npm start

주의
- 이 소스 배포본에는 이전 버전의 dist를 포함하지 않습니다. 반드시 새 빌드를 생성해 사용하세요.
- 실제 비밀번호와 JWT Secret은 ZIP 안에 저장하지 말고 Railway Variables 또는 실행 환경변수로 설정하세요.
- 최초 상태는 Zero State이며 광고주/성과/블로그 샘플 데이터가 없습니다.
